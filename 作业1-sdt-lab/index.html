解读：d′ 越大，两个分布分得越开（分辨能力越强）。β > 1 = 严格，β < 1 = 宽松。 在同一个 d′ 下，移动判定标准只改变 β 和 c，完全不改变 d′——这正是 SDT 的核心分离。

坐标轴读法：纵轴 P(H) = 实际有信号（有毒 / 是鸟 / 赝品 / 不合格） 而你说「有」的比例；横轴 P(FA) = 实际无信号而你说「有」的比例。 曲线上的每一点 = 同一个 d′ 下的一种判定标准。

z 变换 ROC

把坐标轴换成 z 分数后，ROC 变成一条直线。等方差时 slope = 1； 不等方差时 slope = σ(N)/σ(SN)（当前 slope = 1.00）。

现实中人的 zROC 斜率常小于 1——说明信号分布的方差大于噪音分布。

敏感性下降：两种解释

唤醒理论（Welford）：长时间没有事件 → 唤醒水平下降 → 信号与噪音分布相互靠拢。

维持需求理论（Warm）：持续注意消耗有限认知资源 → 资源耗竭 → d′ 下降。

两种理论都预测 d′ 下降，但机制不同：一个说"人不清醒了"，一个说"资源用完了"。

标准偏移与阻止技术

期望理论（Baker）：漏掉信号 → 主观 P(S) 下降 → 调高 β → 更多漏报 → 恶性循环。

阻止技术：目标样例、双眼竞争 / 闪烁、降低事件率、培训、休息、冥想、结果反馈、 虚假信号、置信水平报告、间歇第二任务。
