**记录日期**：2026-11-09

**适用实验**：视觉搜索（Visual Search）、地图对齐（Map Alignment）

## 1. 记录目的

本作业关注两类认知现象：

1. **视觉搜索中的特征搜索与联合搜索差异**：目标在单一特征上独特时，搜索应当相对高效；目标需要结合颜色与形状两个特征时，搜索应当更慢、更容易出错。
2. **地图对齐效应**：当地图方向与参与者当前朝向不一致时，方向判断应当变慢、更容易出错；中央人物线索可能减轻这种不对齐代价，也可能因增加视觉信息而无效或干扰。

预测以方向和相对比较为主。由于本平台是浏览器实验，且正式试次数量有限，本文件不预设具体毫秒数、具体正确率或显著性结论。

## 2. 视觉搜索：设计与预测

### 2.1 设计摘要

- 目标：红色、正立的字母 `O`。
- 反应：`F` = 存在，`J` = 不存在；正式试次无逐试次反馈。
- 集合大小：4、8、16、24。
- 练习：每个 Block 2 个试次，不计入正式分析。
- 正式试次：
  - Block 1 特征搜索（颜色）：10 个；
  - Block 2 联合搜索（颜色 × 形状）：10 个；
  - Block 3 空间位置搜索：15 个（9 个目标存在，覆盖九个区域各一次；6 个目标缺席）。
- 反应时限：4000 ms。
- 分析只使用 `phase = formal` 的试次；练习不进入任何正式统计。

### 2.2 预测

**H1（特征 vs 联合）**  
在正确、未超时的试次中，Block 1（特征搜索）的平均反应时应低于 Block 2（联合搜索）。Block 1 的正确率应不低于 Block 2。

**H2（集合大小效应）**  
Block 2 的正确反应时随集合大小增加而上升的幅度应大于 Block 1。也就是说，若分别拟合“正确反应时 ~ 集合大小”的斜率，联合搜索的斜率应更陡。

> **限制**：Block 1 和 Block 2 各只有 10 个正式试次，4 个集合大小 × 2 种目标存在性共 8 个单元，单个单元只有 1–2 个试次。平台可以给出探索性斜率，但该斜率极不稳定。H2 只作为方向性、探索性预测；即使方向一致，也不能据此声称获得了稳定的搜索斜率。

**H3（目标存在性）**  
目标缺席试次的平均正确反应时应长于目标存在试次，且这一差异在 Block 2 中应更明显。目标缺席时的正确率可能低于目标存在时，但该差异受试次数量限制，只作描述。

**H4（空间位置 Block）**  
Block 3 是探索性 Block。默认 15 个正式试次中，每个区域最多只有一个目标存在试次，因此不预设稳定的区域效应，也不把区域间差异当作确认性结论。可描述目标存在/缺席的正确率与反应时差异，但不将区域排名解释为稳定的空间注意效应。

**H5（速度—正确率权衡）**  
若某条件正确率较低，不能仅凭更短的反应时推断其“更容易”；结果解释应同时报告正确率和正确反应时，并明确提示可能的速度—正确率权衡。

### 2.3 分析口径

- 正确率：全部正式试次，超时/未作答计为错误。
- 平均/中位反应时：只使用正确、未超时、按键有效的正式试次。
- 集合大小分析：分别对目标存在与目标缺席拟合并报告斜率；至少两个集合大小有可用均值时才报告斜率。
- 斜率标注：由于每 Block 只有 10 个正式试次，所有斜率均标注为探索性。
- 眼动/鼠标：WebGazer 指标只在质量阈值达标时描述；鼠标轨迹仅作为行为代理，不与注视数据合并。
- 不把个人斜率与文献斜率做显著性检验；文献只作背景参照。

## 3. 地图对齐：设计与预测

### 3.1 设计摘要

- 固定地图：实验楼在上（0°）、食堂在右（90°）、图书馆在下（180°）、教学楼在左（270°）。
- 地图、建筑标签和指南针在试次间不旋转；每个试次变化的是参与者朝向。
- 两个 Block：
  - `ma_no_cue`：中央为普通红色位置圆点；
  - `ma_person_cue`：中央为俯视小人，头部和身体指向当前朝向。
- 每个 Block：2 个练习 + 15 个正式试次。
- 每个 Block 的正式试次中，朝向 0°/90°/180°/270° 的次数为 3/4/4/4；aligned = 3，misaligned = 12。
- 目标建筑从不等于当前面朝建筑，因此正式试次的正确答案只可能是右方、后方或左方。
- 地图、朝向文字和问题同时出现；默认无反应时限；方向键作答。
- Block 顺序按参与者编号在被试间平衡。

### 3.2 预测

**H6（对齐效应）**  
在两种线索条件合并后，aligned 试次的平均正确反应时应短于 misaligned 试次，正确率应高于 misaligned 试次。即应出现正的地图不对齐代价（misalignment cost）。

**H7（朝向梯度）**  
不对齐代价可能随朝向与地图上方的角度差增大而增大；180° 朝向可能产生最大的反应时代价或最低正确率。该预测为方向性、探索性预测，因为每个 Block 中每个不对齐朝向只有 4 个正式试次。

**H8（人物线索的主效应）**  
与无人物线索条件相比，人物线索条件可能降低整体平均反应时或提高正确率。由于人物图形增加了一个中央视觉对象，也可能出现相反方向或没有差异的结果，因此该预测只作双向描述，不把“人物线索一定有益”视为既定结论。

**H9（线索 × 对齐交互）**  
若人物线索帮助参与者保持当前朝向，则人物线索对 misaligned 试次的改善应大于对 aligned 试次的改善。操作化为：人物线索条件下的不对齐代价（misaligned − aligned）应小于无人物线索条件下的不对齐代价。该交互是本研究最关键的探索性问题之一。

**H10（Block 顺序）**  
Block 顺序按参与者编号平衡，预期不会出现稳定的顺序效应；若出现，应作为方法学限制报告，而不是解释为线索条件本身的效应。

### 3.3 分析口径

- 对齐分类使用真实朝向 `heading_deg`：0° = aligned；90°/180°/270° = misaligned。地图旋转固定为 0，不参与对齐分类。
- 正确率：全部正式试次，超时/未作答计为错误。
- 平均正确反应时：只使用正确、未超时、按键有效的正式试次。
- 不对齐代价：
  - RT cost = misaligned 平均正确 RT − aligned 平均正确 RT；
  - error cost = misaligned 错误率 − aligned 错误率；
  - accuracy cost = aligned 正确率 − misaligned 正确率。
- 线索效应：比较 `person` 与 `none` 两组的不对齐代价；报告 `cue_reduction_ms` 等派生量，并同时报告其方向与不确定性。
- 朝向 × 线索：描述各朝向与两种线索的组合；由于单元试次少，不把单一单元格的差异解释为稳定效应。
- 群体分析：先按参与者汇总，再计算组均值；N < 10 时显示样本不足警告。
- 不做文献均值与个人数据的显著性检验；不编造可比文献数值。

## 4. 样本、排除与报告规则

### 4.1 纳入与排除

正式分析计划纳入完成正式试次的会话。练习试次不进入正式统计。以下情况保留原始记录并在结果中报告，而不是静默删除：

- 超时或未作答；
- 窗口失焦、页面隐藏；
- 无效按键；
- 眼动校准失败、摄像头拒绝或有效注视比例不足；
- 鼠标样本不足。

若未来设定具体的完成率或数据质量排除标准，应在查看正式结果前补充并记录；当前不预设隐藏的排除规则。

### 4.2 报告规则

- 先报告样本量、完成情况、排除情况和数据质量，再报告条件比较。
- 同时报告正确率与反应时，避免只报告更“好看”的指标。
- 所有探索性分析明确标注“探索性”，不把未预设的比较写成确认性结论。
- 不伪造均值、标准差、置信区间、p 值或效应量。
- 若结果与预测方向不一致，按实际方向报告，不修改预测文件来“追认”结果。

## 5. 预测的判定方式

本作业不预设具体的显著性阈值或效应量门槛。结果部分将按以下方式描述：

- **方向一致**：观察到的条件差异方向与预测一致，且样本量与数据质量足以支持描述；仍注明不确定性。
- **方向不一致**：观察到的差异方向与预测相反；如实报告。
- **无法判断**：试次太少、缺失过多、质量不足或置信区间过宽，无法区分方向；不强行下结论。

若未来样本量允许，可使用配对比较、混合效应模型或贝叶斯方法；使用何种模型应在正式分析时记录，而不能根据结果反复选择。当前没有正式数据，因此不预设具体检验结果。
